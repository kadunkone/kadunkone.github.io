Late-event DAU undercount — fixed with a 72-hour lookback

BigQuery · SQL · Pipeline

Problem
DAU was systematically undercounted because late-arriving events were dropped by a narrow processing window.
What I built
A 72-hour lookback in the pipeline so late events land in the correct day's counts, with reprocessing logic to backfill.
What I owned
Diagnosis of the undercount, design of the lookback window, the reprocessing implementation, and validation of the corrected numbers.
What changed
Processing time dropped from ~3 hours to ~20 minutes, and DAU numbers became trustworthy for stakeholders.
Where I can see it
Runs in production behind Tata Elxsi / JLR access — ask me for a walkthrough.

830-entry Python fault-code decoder → pure BigQuery SQL

BigQuery · SQL · Python

Problem
An 830-entry fault-code decoder lived in Python, outside the warehouse — diagnostics were slow to run and hard to audit.
What I built
Converted the entire 830-entry decoder into pure BigQuery SQL, plus diagnostic join-safety queries.
What I owned
The full conversion and entry-for-entry validation that the SQL version matched the original Python logic.
What changed
Diagnostics now run where the data lives — no Python dependency in the loop, and the logic is auditable in SQL.
Where I can see it
Client-side; ask me for a walkthrough.
